## 1. 무엇을 만들고 있는가

본사가 직영 4개점을 운영한 경험을 바탕으로 전국 30개점 한정 가맹 파트너를 모집하는 한국어 랜딩입니다. 대표 고한빈의 브랜드이며, 방문자는 헤드스파를 배우려는 사람만이 아니라 사업성과 운영 가능성을 검토하는 예비 점주입니다.

의사결정 흐름은 “관심 → 직영 운영 근거 → 내 수익 이해 → 고객이 구매할 이유 → 고객 유입 방법 → 운영 가능한 이유 → 예산·지역 적합성 → 현장 확인·상담”입니다.

대표님은 강한 훅과 구체적 자료를 선호합니다. 말투는 자연스럽고 직설적으로 쓰되, 매출 보장이나 확인되지 않은 치료 효과를 단정하지 않습니다. 내용의 길이 자체보다 반복·시각적 단조로움·문단 사이 단절이 문제입니다.

## 3. 디자인 방향

기준 색상은 `app/refined.css` 토큰입니다: 와인 `#641522`, 잉크 `#2c2120`, 크림 `#fbf8f3`, 옅은 면 `#f1e8df`, 선 `#d9c9bf`, 보조 글자 `#78665e`.

이미지와 여백이 충분한 편집형 랜딩을 지향합니다. 큰 숫자와 문장은 선택적으로 쓰고, 모든 카드·제목을 동시에 움직이지 않습니다. 전체를 슬라이드/캐러셀로 바꾸거나, 녹색 면·형광 그라데이션·같은 카드 격자를 반복하지 않습니다. 손글씨/세리프를 남발해 광고 문구를 장식하지 말고 읽기 편한 한글을 우선합니다.

현재 메뉴별 가격표는 삭제된 상태입니다. 서비스 설명 영상은 남아 있습니다. 다시 가격 메뉴를 넣는 것은 별도 요청 사항입니다.

패키지의 이미지가 전부 실제 고객 사진이라는 뜻은 아닙니다. `public/images/personas/`는 상황 설명용 이미지로 사용된 영역입니다. 실제 고객 인증 사진이나 치료 전후 증거로 재사용하지 마세요.

의학적 발모·치료 효과나 “뾰루지가 모두 없어졌다” 같은 후기를 창작해 실제 방문 후기처럼 만들지 않습니다. 시장 통계와 1위 등은 출처·기준일을 별도로 재확인해야 합니다.

## 5. 손익 모델의 현재 계산

단위는 만원, 부가세 제외 가정입니다. `lib/franchise-economics.ts`가 원본입니다.

- 제품비 10%, 마케팅비 10%, 로열티 10%, 결제수수료 2%: 변동비 합계 32%.
- 테라피스트 5명 × 300 + 상담·운영 1명 × 350 = 인건비 1,850.
- 월세 300, 기타 150, 감가상각 200. 고정비 합계 2,500.
- 영업이익 = 매출 × 0.68 − 2,500. 세금·대출이자 차감 전.
- 월매출 3,500 / 5,000 / 7,000이면 영업이익 −120 / 900 / 2,260.
- 손익분기 월매출 약 3,676.47.
- 객단가 기본 11, 월 26일, 테라피스트 5명·베드 5개·1인 6건 가정.
- 회수 계산의 투자금은 동탄형 1.4억 / 천안형 2.2억 가정. 현재 월 영업이익으로 나눈 단순 계산이며 실제 회수 실적이 아님.

그래프와 표를 보기 좋게 수정해도 계산식과 표시 단위를 분리해서 검증해야 합니다. 과거 메모의 마진율/회수 4개월·6개월 수치를 현재 계산에 덮어쓰지 마세요.

## 7. v41에서 다듬은 동작

- 핵심 세 곳(직영 실적 도입, 손익 제목, 마케팅 도입)에만 문장 등장 효과. 고객/교육/FAQ의 반복 등장 효과는 제거.
- 히어로·본문 주요 상담 버튼·문의 폼이 보일 때 고정 CTA 숨김. 메뉴/팝업이 열린 동안에도 고정 CTA 숨김.
- 모바일 헤더의 별도 상담 버튼을 없애고 메뉴 안에는 상담 링크 유지.
- 수익과 마케팅을 각각 일정 시간(6초) 살펴본 방문자에게 운영 지원 도입부에서 방문 상담 팝업 제안. 스크롤 정지 후 1.6초, 입력/메뉴/동영상·포커스 상태 확인.
- 팝업은 세션당 한 번. 상담을 이미 선택했으면 추가 팝업 억제.
- 방문 신청 시 문의 내용 자동 채움. 팝업에서 신청하면 이름 입력란으로 연결.
- 배경 영상은 muted/inline autoplay를 시도하며 재생 제어 제공. 브라우저/절전 정책에 따라 자동 재생이 제한될 수 있어 실기기 확인 필요.
- reduced-motion 대응, 모바일 타이포·포커스·화면 높이 조정.
