# SCALPIT 프로젝트 인계

먼저 `README.md`와 `HANDOFF.md`를 읽고 실제 코드와 대조하세요. 본 문서는 프로젝트 맥락이며, 대표님의 이후 명시적 요청이 우선합니다.

## 목적

메타·유튜브 광고로 유입된 한국 예비 가맹점주가 스칼프잇의 사업성과 운영 지원을 이해하고 가맹·직영점 방문 상담을 신청하게 하는 사이트입니다. 일반 소비자용 예약 홈페이지가 아닙니다.

## 유지할 방향

- 와인 레드·레드 브라운, 크림, 절제된 코퍼. 초록 배경은 사용하지 않습니다.
- 공식 로고·실제 매장 사진·실제 영상 중심. 동일한 카드와 효과를 반복하는 디자인을 피합니다.
- 기존의 긴 설명 흐름을 무작정 축약하지 않습니다. 대표님은 과거 전면 축약본보다 상세한 기존 구성을 선호했습니다.
- 인스타그램은 사진·타이포 감도의 참고입니다. 홈페이지 전체를 캐러셀로 구성하라는 의미가 아닙니다.
- 메뉴 가격 카드는 대표님 요청으로 제거했습니다. 요청 없이 다시 넣지 않습니다.
- 핵심 표현: “1년 만에, 직영 4개.” / “그래서, 얼마 남는데?” / “광고를 도와드리지 않습니다. 직접 다 해드립니다.” / “JUST SCALPIT.”
- 8가지 고객 수요, 실제 리뷰, 본사 마케팅, 2+1+1주 교육, 매월 정기 교육, 출점 조건과 방문 상담을 유지합니다.
- ZERO는 광고 실무 부담입니다. 광고 집행비 무료라는 의미가 아닙니다.
- 가상 매출·손익·예약·리뷰를 실제 실적으로 바꾸거나 예시 표기를 숨기지 않습니다. 자료를 받으면 교체합니다.
- 실제 문의 전송이나 공개 배포는 디자인 확인과 구분합니다. 요청 없이 운영 사이트에 테스트 고객 정보를 보내지 마세요.

## 기술

React 19 + TypeScript + Vinext/Vite + Cloudflare Workers/D1 + Tailwind 4 + Radix UI. 일반 Next.js 단독 배포로 가정하지 마세요. `package.json`, `pnpm-lock.yaml`, 실행 구조를 보존합니다.

## 현재 생명주기와 파일

- `app/page.tsx`: 실제 단일 랜딩, 데이터 배열, 문의 폼, 방문 팝업.
- `app/layout.tsx`: 메타데이터와 활성 CSS import 순서.
- `app/globals.css` → `app/direction.css` → `app/refined.css` → `app/experience.css`: 현재 활성 스타일. 나중 규칙이 앞선 규칙을 덮으므로 실제 cascade를 확인하세요.
- `components/brand-film.tsx`: 배경 영상 자동 재생, 모바일 영상, 재생 제어.
- `components/scalpit-experience.tsx`: 핵심 구간 등장 효과, 숫자, 진행 표시, 스크롤 연출.
- `lib/franchise-journey.ts`: 상담 CTA 노출과 읽기 맥락에 따른 방문 팝업.
- `components/revenue-studio.tsx`, `lib/franchise-economics.ts`: 손익 계산.
- `components/franchise-assurance.tsx`: 재방문·업무 분담·매출 하락 대응·투자비 검토.
- `app/api/inquiries/route.ts`, `lib/inquiries.ts`, `db/`, `drizzle/`: 문의 저장.
- `public/`: 로고, 실제 지점 사진, 리뷰 이미지, 상황별 이미지, 영상.

다른 `franchise-*` 컴포넌트와 CSS에는 과거 버전이 남아 있습니다. 파일명만 보고 수정하지 말고 import 사용 여부를 먼저 확인하세요. 특히 `app/launch.css`와 `components/franchise-motion.tsx`는 현재 메인 구현이 아닙니다. `CONTENT_NOTES.md` 역시 초기 기록으로, 현재 v41 동작을 설명하지 않습니다.
