## 2차: 비어 있던 설득 논리를 시안으로 채움
예비 점주가 결정 전에 따지는 순서(관심 → 근거 → 수익 → 고객 → 유입 → 운영 → 반박 → **투자·조건** → 확인 → 상담) 중 빠져 있던 "투자·조건"과 "본사 리스크 반박"을 채웠습니다.

| 추가 | 내용 | 위치 |
|---|---|---|
| 창업 비용 (`#terms`) | 1·2·3·5억 모델을 눌러 보면 가맹비·교육비·인테리어·장비·운영자금 구성과 합계가 바뀝니다. 비율 막대와 "이 표에 없는 돈" 안내, 모델 선택 후 바로 상담으로 연결 | `app/page.tsx` |
| 매달 나가는 돈·계약 조건 | 로열티, 마케팅 분담금, 계약 기간, 영업지역 보호, 양도·양수, 오픈까지 기간 6개 카드 | `app/page.tsx` |
| 반박 4번째 | "본사가 중간에 손 놓으면요?" — 직영 4곳 운영, 정보공개서, 계약 전 확인 절차로 답변 | `app/page.tsx` |
| 연결 | 핵심 요약 1번 카드가 비용 섹션으로 이동. FAQ "가맹비·로열티"가 같은 숫자를 자동 인용 | `app/page.tsx` |

**모든 금액·조건은 시안입니다.** 값은 전부 `lib/franchise-terms.ts` 한 파일에 있습니다.
1. 그 파일의 숫자·문구를 실제 정보공개서 기준으로 바꾸세요.
2. 맨 위 `TERMS_VERIFIED`를 `true`로 바꾸면 화면의 "시안" 표시(안내 줄, 카드 태그, FAQ 문구)가 한 번에 사라집니다.
- 시안 값은 기존 계산 가정(로열티 10%, 마케팅 10%)과 맞췄고, 모델별 합계가 1억·2억·3억·5억이 되도록 구성했습니다.
- 영업지역 보호(반경 1km), 계약 기간(5년), 양도 가능 같은 정책은 제가 임의로 정한 값입니다. 실제 정책과 다르면 반드시 고치세요.

## 3차(최종): 벤치마킹 결과 반영
| 항목 | 내용 |
|---|---|
| 비용표 | "이 표에 없는 돈"을 항목별로 분리(점포 보증금·환급 표시, 권리금, 추가 공사, 부가세, 대출 이자·생활비)하고 기준 문구를 표 위에 표시. 1억 모델에 "처음 시작하기 좋은 규모" 라벨 |
| 절차 | 계약 전 4단계를 7단계 타임라인으로 확장: 단계별 소요 기간, 본사가 하는 일/점주가 하는 일, 계약 전·후 구분, "정보공개서 최소 14일(법정)", "어느 단계에서든 멈춰도 됩니다" |
| 출점 기준 | 출점 검토 기준표 6항목(규모·층·상권·월세 수준·설비·제외 입지) + "희망 지역을 알려주시면 상권을 함께 검토" |
| 반박 | 4개 → 7개: 억대 매출은 평균인가 / 폐점도 공개하나 / 선착순이라며 재촉하지 않나 |
| 인력 | "테라피스트가 그만둬도 매장이 흔들리지 않게" 6단계(채용→교육→실기 점검→역할 확대→보수교육→결원 대비). 자격증이 아닌 자체 점검표임을 명시 |
| 교육 | 20영업일 = 본사 8일 + 직영 실습 12일, 오픈 후 슈퍼바이저 월 2회, 정기교육 월 1회 |
| 방문 상담 | "1:1 창업 코칭"으로 개명, 희망 시간대 선택(선택 시 문의 내용에 자동 입력). 잔여석·마감 표시는 쓰지 않음 |
| 폼 | 필수 입력은 그대로 4개. "더 알려주시면 상담이 빨라집니다(선택)"에 창업 시기·투자 가능 금액·통화 시간을 접어 둠(문의 내용에 합쳐 전송, 서버 변경 없음). 접수 완료 화면에 다음 3단계 안내 |
| 안내서 | "가맹 안내서 요청" 띠 추가(누르면 폼 문의 내용에 자동 입력) |
| CTA | 기본 CTA 문구를 "가맹 상담 신청"으로 통일(헤더·메뉴·모바일 하단·출점 기준·예산·폼 버튼) |
| 모바일 | 계약 조건 6카드를 좌우 넘김으로, 반박·절차·인력 블록 밀도 조정 |

시안 값은 모두 `lib/franchise-terms.ts`에 있고 `TERMS_VERIFIED=true`로 "시안" 표시가 사라집니다. 소요 기간, 입지 기준, 방문 시간대, 교육 일수, 인력 단계는 제가 임의로 정한 값이니 실제 운영과 다르면 바꾸세요.

**대표님이 준비해야 하는 것**
- "가맹 안내서 요청"은 요청을 접수하는 버튼입니다. 안내서(PDF) 자체는 아직 없습니다. 비용·절차·FAQ 8~10쪽을 만들어 상담 연락 때 보내거나, 요청 시 제가 현재 화면 기준으로 만들 수 있습니다.
- 방문 시간대(화·목 14시, 토 11시)는 실제로 운영할 수 있는 시간으로 바꾸세요.
- 모바일 전체 길이가 약 32,000px에서 약 41,000px로 늘었습니다. 실데이터를 넣은 뒤 덜 중요한 블록은 접거나 줄이는 정리가 필요합니다.

## 광고 집행 전에 반드시 필요한 것 (제가 만들 수 없는 것)
1. **실제 매출·예약 자료로 교체** — 동탄·천안 월별 그래프/엑셀, 예약 달력, 외국인 비중, 마케팅 도달→예약 지표가 전부 "가상 수치"입니다. 지금은 라벨로 정직하게 표시돼 있지만, 이 섹션이 사이트의 신뢰를 가장 크게 좌우합니다.
2. **정보공개서 등록** — 가맹 모집·광고 전에 공정위 정보공개서 등록이 필요합니다. 등록 후 번호를 푸터에 표기하세요. 이번에 추가한 "정보공개서 14일" 문구는 법정 절차를 그대로 쓴 것입니다.
3. **"1위" 표기 근거** — 검색일·위치·키워드·캡처를 확보하세요(검색 순위는 `f-rank-table`).
4. **가맹 조건 확정** — 위 2차에서 시안으로 채운 가맹비·교육비·영업지역 보호·계약 기간·양도 조건을 실제 값으로 교체(`lib/franchise-terms.ts`).
5. 배포 도메인이 정해지면 `NEXT_PUBLIC_SITE_URL` 환경변수 설정(공유 이미지 주소에 쓰임).
